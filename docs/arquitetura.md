# Relatório de Arquitetura e Modelagem

## Projeto FilaMedSchool

O FilaFácil é uma proposta de aplicativo para facilitar o acompanhamento de filas de atendimento nas enfermarias de escolas.

A solução permite que o usuário entre no aplicativo, escolha o tipo de atendimento desejado e entre na fila. Depois disso, o sistema apresenta a posição do usuário e uma estimativa do tempo de espera.

O objetivo é permitir que o usuário acompanhe a fila pelo aplicativo, evitando a necessidade de permanecer no local durante todo o período de espera.

## Fluxo da solução

O funcionamento básico da solução é:

1. O usuário entra no aplicativo.
2. O usuário escolhe o atendimento.
3. O usuário entra na fila.
4. O sistema mostra a posição e o tempo de espera.
5. O usuário acompanha a fila.
6. O usuário é chamado para o atendimento.

O fluxograma desenvolvido representa visualmente esse processo.

## Modelagem

O fluxograma foi desenvolvido utilizando o Draw.io e representa o fluxo inicial de funcionamento do aplicativo.
